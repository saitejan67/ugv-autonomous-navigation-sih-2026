# UGV Autonomous Navigation — SIH 2026

Vision-based autonomous navigation for an unmanned ground vehicle in outdoor environments.

## Problem Statement
- Path detection and traversability estimation
- Visual localization without GPS
- Dynamic obstacle avoidance
- Autonomous navigation from Point A to Point B

## Planned Stack
- ROS 2
- Gazebo for lightweight development/testing
- Isaac Sim for high-fidelity simulation on the stronger workstation
- OpenCV / perception AI
- Visual SLAM / odometry
- Nav2 / path planning

## Repository Structure
This repository will contain the ROS 2 workspace and simulation/integration packages.
